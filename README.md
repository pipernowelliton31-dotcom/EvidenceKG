# GraphMind · 资料问答与知识图谱

GraphMind 将 PDF、Word、Excel、PPT、图片及文本资料组织为可追溯的事实和知识图谱，在本地 Web 应用中完成问答、原文核对和关系探索。前端使用 React / TypeScript / Vite，后端使用 FastAPI，解析与检索复用 `system/skill/evidence-kg-builder`。

本应用按本机单用户场景设计，默认只监听 `127.0.0.1`。在线回答和语义构图使用你配置的模型 API，不会借用其他聊天应用的模型或密钥。

- **图谱探索**：统一业务关系、产品架构、完整图谱、本轮问答四种视图；支持实体搜索、关联关系筛选、网络图旋转和图谱 JSON 导出。

完整的行为变化、实现文件、兼容性与验证记录见 [change.md](change.md)。本次使用日期标识更新，没有改动后端现有版本字段，也没有创建版本标签。

## 快速启动：Windows 便携运行

仓库包含便携 Python 运行时及前端生产文件。Windows 下在仓库根目录双击 **`启动系统.bat`**，保持启动窗口打开。

启动器会自动打开浏览器，通常访问 `http://127.0.0.1:8000`。如果端口被占用，会在 8000～8019 中选择可用端口，以窗口打印的 `URL:` 为准。按 `Ctrl+C` 停止服务。

也可以在仓库根目录的 PowerShell 中运行：

```powershell
.\system\runtime\python.exe -I -B -X utf8 .\system\tools\portable_start.py --no-browser --port 8000
```

此命令只启动服务，不自动打开浏览器。静态前端更新后刷新页面；更新已经运行的后端代码后，需要自行停止并重新启动服务。

## 模型与密钥配置

### 方式一：界面配置自己的 API

打开左侧“模型设置”，填写兼容 Chat Completions 的 API 地址、模型 ID 和 API 密钥，然后选择“保存并测试连接”。地址填写服务商规定的 Base URL，程序会追加 `/chat/completions`。

连接测试会实际请求所选服务商，可能产生费用。它只验证文本连接，不验证图片输入能力。含图片的资料完整构图需要模型及服务商路由支持图片输入；已有知识库的文字问答可以使用纯文本模型。

自定义密钥在 Windows 上通过 DPAPI 保护，保存在本机 `system/runs/web/local_api.json`。网页保存的配置优先于环境文件；切换到内置模式后，再切回仍可沿用原有自定义配置。

### 方式二：使用内置 API 密钥进行评审测试

在仓库根目录执行一次，复制不含任何密钥的模板：

```powershell
# 已有 system/.env 时直接编辑现有文件，不要覆盖。
Copy-Item .\system\env.example .\system\.env
notepad .\system\.env
```

填写需要使用的 `BUILTIN_DEEPSEEK_API_KEY`、`BUILTIN_OPENROUTER_API_KEY` 或 `BUILTIN_OLLAMA_API_KEY`，然后在“模型设置”开启“使用内置API密钥进行测试”，选择服务商和模型并保存。

| 服务商 | 环境变量 | 可选模型 |
| --- | --- | --- |
| DeepSeek | `BUILTIN_DEEPSEEK_API_KEY` | `deepseek-flash`（开启内置模式时的默认选择） |
| OpenRouter | `BUILTIN_OPENROUTER_API_KEY` | `nvidia/nemotron-3.5-super-vl:free`（该服务商默认）、`dots-studio/dots-3-note-preview:free`、`deepseek/deepseek-v4.1-flash-1017` |
| Ollama Cloud | `BUILTIN_OLLAMA_API_KEY` | `gemma4:31b`（唯一选项） |

各服务商使用各自固定地址及后端模型允许列表，Ollama Cloud 使用 `https://ollama.com/v1`。没有配置对应密钥时不能保存该内置选择或测试连接。程序不会将内置密钥回传前端或复制进本地模型选择配置。模型名称是当前应用的配置列表，实际可用性及计费以服务商为准。

服务端读取的环境文件位于 **`system/.env`**，不是仓库根目录。系统环境变量优先于该文件，已保存的自定义网页设置再覆盖对应默认值。不要使用 `VITE_` 变量保存密钥。

模板还提供可选的自定义默认项：`OPENROUTER_API_KEY`、`OPENROUTER_BASE_URL`、`LLM_MODEL`、`LLM_REASONING_EFFORT`。不支持思考参数的服务商可将最后一项留空。

## 使用 Web 应用

### 资料库和构图

1. 从左侧选择资料库，或点击“上传资料”创建新资料库／补充当前可编辑资料库。
2. 支持 PDF、DOCX、XLSX、PPTX、PNG、JPEG、WebP、Markdown 和 TXT，可选多文件或文件夹。每批最多 50 个文件，单文件不超过 80 MB，总计不超过 300 MB。
3. 在“原始资料”确认资料用途。业务资料参与构图；问题集和参考资料排除。新增或移除文件后，需要重新解析构图才能针对新资料进行问答。
4. 点击“解析资料并生成图谱”。原始图片与语义任务会使用当前模型；失败后可保留检查点续跑。

仓库已有的演示数据以实际来源核验结果为准。原文件、哈希或知识库不完整时，应重新构图，不会把旧图谱当成新资料的结果。

### 连续问答与上下文

输入框自动选择普通对话或资料问答，无需手动切换模式。简单问候及纯算式由本地规则识别，其余请求由当前模型分类；分类失败或超过 15 秒回退资料问答。分类可能增加一次模型调用。

普通对话不要求资料库已经构图；资料问答仍要求有效知识库，并展示来源与图谱入口。没有 API 配置时，可以浏览已有离线资料和图谱，不能生成在线回答。

同一对话通过父轮次关联上下文，打开历史后可继续追问：

| 环节 | 当前上下文范围 |
| --- | --- |
| 问题分类 | 最近六轮问题、回答和实际回答模式；最多 4000 字符的资料名称及实体摘要 |
| 资料检索 | 当前问题和最近两轮的问题 |
| 模型回答 | 最近六轮问答，每轮问题最多 3000 字符、回答最多 6000 字符 |

历史用于理解追问，不替代本轮证据。检索目前没有将历史回答中的指代先改写成完整问题，复杂的“他／它／那个”追问仍可能召回不足。点击“新对话”或切换资料库会重新开始上下文。

回答支持流式显示、停止、失败重试和长度截断后的自动接续。模型设置可调整输出预算和思考强度；接续受后端保存的次数限制，额外调用按服务商计费。

### 原文、图谱与表格

资料回答结束后，可从“查看来源与原文”打开右侧证据面板，核对文件、摘录及定位。关联图谱可切换范围与路径，并搜索关系。原文文件、用途、图谱范围与路径选择器不额外增加搜索框。

知识图谱主页提供“业务关系／产品架构／完整图谱／本轮问答”。可以搜索实体，筛选它的关联关系，或直接点选画布节点和连线。网络图支持旋转、缩放和暂停，产品架构和路径图保持平面布局。

Excel 预览保留原始坐标、空值、公式、批注、隐藏标记及合并信息，支持横向和纵向滚动。表格及证据面板跟随白天／夜间主题。输入框的资料库名称支持悬停展开文件总览。

### 对话管理和导出

- 最近对话的更多菜单可导出或删除整条对话；标题右侧可清空当前资料库问答历史。删除会移除本机保存的 JSON，运行中的问答须先停止。
- **聊天记录 Markdown**：仅问题与回答，适合继续编辑。
- **完整日志 JSON**：保留轮次、模式、模型、来源、执行事件、图谱和已记录用量；自动路由只保存分类结果、来源、耗时和数值用量。
- **分享网页 HTML**：下载离线网页，渲染基础 Markdown；不会上传到分享服务或生成公开链接。
- **图谱导出**：思维导图 HTML 用于离线展示，知识图谱 JSON 用于核验数据。
- **原始资料 → 备份与恢复**：ZIP 包含图谱、解析正文、事实及解析资产，不保证包含全部原始 Office/PDF 文件；原文件另行保管。

十题问答只对测试集 A 开放，每题使用强制资料问答且上下文独立。批量调用会产生服务商费用；成功生成答案不等于评分通过。

## 源码开发与验证

便携运行不需要安装 Node.js。修改前端源码时，使用 Node.js 20.19+ 或 22.12+ 和 npm，以满足当前锁定的 Vite 依赖要求。

```powershell
# 仓库根目录：建立独立 Python 环境并安装 Web 依赖。
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\system\app\requirements.txt

# 构建前端。
Set-Location .\system\app\frontend
npm ci
npm run build
Set-Location ..\..\..

# 使用独立 Python 环境启动后端。
.\.venv\Scripts\python.exe .\system\tools\start_web.py
```

开发服务器：在 `system/app/frontend` 执行 `npm run dev`，默认将 `/api` 代理到本机 8000，后端需单独启动。生产服务读取 `frontend/dist`，仅编辑 `src` 不会更新生产页面。

本地测试不要求真实付费模型调用：

```powershell
# 仓库根目录：Python 回归测试。
.\system\runtime\python.exe -I -B -X utf8 -m unittest discover -s .\system\tests -v

# 前端目录：上传、导出、路由展示及生产构建。
Set-Location .\system\app\frontend
npm run test:workspace
npm run test:routing
npm run build
```

默认 `npm test` 只执行 `test:workspace`，路由测试需显式运行。测试和构建不代表已完成浏览器交互验收或真实供应商验证。

## 提交范围与本地数据

发布只包含程序、必要静态文件、文档、空密钥模板和测试代码。以下内容保留在本机：

- `system/.env`、其他真实环境文件及 `local_api.json`。
- `system/runs/web/runs/` 新生成的问答记录、流式事件和分类日志。
- Python 字节码、Vite 开发缓存及 TypeScript 构建缓存。

公开的示例模板是 [system/env.example](system/env.example)，其中密钥值为空。运行记录排除规则只阻止新文件加入；早期提交已经包含的历史文件不会因添加忽略规则而自动移除，本次也没有重写历史。
